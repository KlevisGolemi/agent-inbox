# Agent Inbox 2.2 — Cadrage validé (brainstorming du 2026-10-02)

Source de vérité pour écrire la spec 2.2. Décisions prises avec Klevis ; ne rien perdre au compactage.

## Vision

Agent Inbox devient une **boîte aux lettres pour LLM** : un pont entre agents, outils et machines.
Claude (Desktop/Web/Code/Cowork), ChatGPT, Codex, n8n ou un logiciel sans MCP peuvent **déposer** et **relever**
du JSON, des fichiers, des zips. Exemples cibles :
- Codex génère du code sur une machine → l'envoie en zip → Claude Code le récupère ailleurs, dézippe, travaille.
- En déplacement sur ChatGPT, quelqu'un t'envoie une image → « regarde ce qui est arrivé dans l'Agent Inbox ».
- Un LLM produit un fichier → un autre le reprend.

## Décisions

1. **Pièces jointes de tous types** (image, audio, PDF, binaire, zip). Pas de notion de dossier : **les dossiers voyagent en zip**.
2. **Limites entièrement paramétrables à chaud (en base, sans redémarrage)** : taille max du JSON (aujourd'hui 1 Mo fixe →
   réglage, ex. 10 Mo), taille max par catégorie de fichier (image, audio, fichier, zip…), types autorisés.
3. **Jauge disque** : quota global + espace disponible réel ; visible dans le MCP (outil/stats) et dans l'admin
   (barre de remplissage). Les envois sont refusés/filtrés selon l'espace disponible.
4. **Rétention paramétrable par règles** (type et/ou poids → durée), ex. « > 50 Mo : 24 h », « image : 7 j ».
5. **Deux modes de livraison** selon le client :
   - **inline** (contenu MCP natif, image affichée) pour les petits fichiers (≈ ≤ 5 Mo, réglable) → Claude Desktop/Web ;
   - **lien de téléchargement signé et temporaire** pour les gros fichiers → Claude Code, Cowork, Codex, ChatGPT
     téléchargent dans un dossier et travaillent dessus.
6. **Deux comportements au téléchargement** : *consommer* (le fichier est consommé à la récupération) **ou** *laisser
   disponible* pendant un TTL (ex. 24 h) puis suppression automatique.
7. **Audio et autres formats** : transmis tels quels ; c'est le client qui sait les traiter (ex. ChatGPT avale l'audio).
   **Pas de transcription côté serveur** (reporté).
8. **Tags intelligents = registre de tags** :
   - tag = objet : nom normalisé, **description obligatoire** (pourquoi il existe), créateur (Claude/GPT/n8n…), compteur d'usage ;
   - le LLM **vérifie d'abord les tags existants** avant d'envoyer, réutilise le bon, n'en crée qu'en dernier recours ;
   - les tags existants les plus utilisés sont **injectés dans la description des outils** (`tools/list`) → l'agent les voit dès
     la première requête ;
   - **anti-doublon** : à la création, si un tag proche existe, le serveur le signale (« tag similaire : … ») ;
   - tags automatiques gratuits (type, source, topic, taille) + outil `queue_tag` pour que l'agent tague ;
   - **pas de tagging par LLM côté serveur** (pas de clé API ni de coût).
9. **Dépôt public par des tiers (option B validée), bien encadré — les « drops »** :
   - liens **générés à la demande** (admin ou agent via outil `inbox_create_drop`), jamais d'adresse figée ;
   - par lien : expiration (24 h par défaut, réglable), nombre d'envois max, taille et types autorisés, topic + tags de
     destination, libellé ; révocable ; historique des envois ;
   - mini-page web d'upload (glisser-déposer) + commande curl ;
   - tout contenu arrivé par un drop est **marqué « externe non vérifié »** et signalé par les outils (risque d'injection de
     prompt : donnée, jamais instruction).
10. **Skill « Agent Inbox »** livré avec le projet : skill + une référence par outil/option ; enseigne la routine des tags,
    les modes de livraison, le traitement prudent du contenu externe.
11. **Finalisation** : README refait, tests complets, vérification à 100 % (local + prod), captures/GIF à jour, déploiement prod.

## Défis retenus / hors périmètre 2.2

- « Pas de limite » n'existe pas : quota disque obligatoire (VPS ≈ 55 Go libres partagés avec n8n, Twenty…).
- Réponses d'outils MCP limitées à quelques Mo côté client → au-delà, toujours par lien signé.
- Reportés : transcription audio serveur, tagging LLM serveur, notion de dossier hors zip.
